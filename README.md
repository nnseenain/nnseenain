Hi! I'm Nnsée (pronounced enn-say) and I'm a Lead Product Engineer from London 🇬🇧 and the organiser of the [London TypeScript meetup](https://www.meetup.com/london-typescript-meetup/).

I wrote my first program aged 9 in BASIC and never stopped from there. From C++ and C# to TypeScript and Rust today. These days I build agentic AI workflows wrapped in deterministic gates and evals.
